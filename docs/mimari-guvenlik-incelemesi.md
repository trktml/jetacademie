# Mimari ve Güvenlik İncelemesi

Tarih: 4 Kasım 2026. Kapsam: Next.js uygulaması, kimlik doğrulama/hesap uçları, müfredat erişimi ve ilerleme, editör sınırları, istemci önbelleği, bağımlılıklar ve doğrulama süreci.

## Değerlendirme

Server Components, TanStack Query ve Zustand ayrımı uygulamanın boyutuna uygundur. Mikroservis, genel amaçlı repository sınıfı veya ek DI çatısı gerekmiyor. Başlıca sorunlar modüller arası gereksiz bağımlılıklar, tekrarlanan istek işleme, örtük güven varsayımları ve atomik olmayan veri işlemleriydi.

## Doğrulama

- `bun run test`: **436 test geçti, 0 hata**; 63 dosyada mevcut testler ve 18 ek mimari/tutarlılık regresyonu. Test komutu uygulama adreslerini de sabitler; geliştiricinin `.env` adresi test sonucunu değiştirmez.
- `bun run test:postgres`: ayrı PostgreSQL 16 üzerinde geçici şema; geri alma, eşzamanlı deneme bütçesi/kayıt, parola değişiminde diğer oturumların iptali, ilerleme sırası, aktarım, taslak/yayın görünürlüğü, çok parçalı yazmanın geri alınması, eşzamanlı paket/editör kaydı ve anlık görüntü revizyonları geçti.
- `bun run lint`, `bun run format:check`, `bun run build`: başarılı; lint uyarısı yok.
- `bun audit`: 680 paket denetlendi; bilinen açık bildirilmedi.
- Yerel tarayıcı kontrolü: sıralı/haftalık görünüm, PDF yükleme/sayfa geçişi, editör girişi, art arda iki kayıt, kaydedilmemiş metnin korunması, hesap girişi, ilerleme tamamlama/geri alma ve çıkışta özel ilerlemenin kaldırılması doğrulandı.
- Docker: Bun 1.4.4 ile imaj derlemesi ve standalone çalışma başarılı; temiz PostgreSQL üzerinde başlangıç, müfredat, eşleşen CSP nonce ve yerel PDF worker doğrulandı. Konteyner UID 1001 ile çalışır. Yedekler, araştırma kaynakları, özel anahtar dosyaları ve üretilmiş varlıklar derleme bağlamından dışlanır.
- GitHub Actions: aynı kapılar; PostgreSQL servisi, salt okunur depo izni ve SHA'ya sabitlenmiş eylemler.

## İşletim Sınırları

Bu çalışma kod ve yerel ortam incelemesidir; canlı sunucuya dağıtım veya dış ağdan sızma testi yapılmadı. Yerel testler canlı firewall, Tailscale ACL, TLS sonlandırma, sunucu erişimleri veya yedeklerin geri yüklenebilirliğini kanıtlamaz.

Üretim URL'leri aynı HTTPS kaynağını göstermeli; veritabanı parolası, Better Auth sırrı ve ayrı editör kimlik bilgileri ortamda sağlanmalıdır. Eski kısa parolalarla giriş uyumluluğu korunur; yeni parola ilkesi yalnız kayıt/değiştirmede uygulanır. Ortak giriş/kayıt bütçesi saldırı sırasında meşru kullanıcıları da sınırlayabilir; yoğun trafik için proxy seviyesinde istemci/IP sınırları gerekir. Bu kod, başlıklardan güvenilir istemci IP'si varsaymaz.

Nonce kullanan CSP HTML'i dinamik oluşturur; sayfa üretimi ve veritabanı kapasitesi buna göre izlenmelidir. Stil niteliği kullanan bileşenler nedeniyle inline stiller; dış PDF kaynakları nedeniyle HTTPS bağlantıları açıktır. Paket denetimi yalnız bilinen bağımlılık duyurularını kapsar ve gelecekte yeni açık bulunmayacağını garanti etmez.

Temel kaynaklar: [Next.js güvenlik duyurusu](https://github.com/advisories/GHSA-673q-mjm6-r5xr), [Better Auth güvenlik duyurusu](https://github.com/advisories/GHSA-965c-763c-88jm), [Better Auth hız sınırları](https://better-auth.com/docs/concepts/rate-limit), [OWASP kimlik doğrulama rehberi](https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html). Duyuruların bazıları uygulamada etkin olmayan özelliklere ilişkindir; paket güncellemeleri bu özelliklerin ileride kullanılmasını da güvenceye alır.
